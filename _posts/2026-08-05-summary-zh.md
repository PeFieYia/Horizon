## [Deno 的 Celld 将 Durable Objects 引入自托管运行时](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno 发布了 celld，这是一个自托管的分布式 Durable Objects 运行时，运行 V8 隔离实例，内置 SQLite 和 S3 复制，支持不依赖特定提供商的持久对象执行。这个开源项目允许开发者在单一云提供商之外运行 Durable Objects，填补了生态系统中的一个重要空白。 这意义重大，因为它使 Durable Objects 抽象变得大众化，而这一抽象一直是 Cloudflare Workers 的关键差异化优势。通过使其可自托管，开发者现在可以构建可移植的有状态分布式应用，避免供应商锁定，并可能影响更广泛的边缘计算和无服务器领域。 Celld 将每个 Durable Object 作为 V8 隔离实例运行，拥有自己的 SQLite 数据库，并将数据复制到用户拥有的 S3 兼容存储桶。它没有使用 deno_core，展示了新的运行时方法，并且由于隔离实例的轻量特性，空闲成本非常低。

hackernews · calvinfo · 8月5日 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**背景**: Durable Objects 是由 Cloudflare 推广的概念，提供全局唯一、单线程的计算实例，并具有持久存储，通常基于 Actor 模式。V8 隔离实例是在共享的 V8 进程中运行代码的轻量级沙箱，可实现快速启动和低开销。S3 复制涉及将数据复制到多个位置以实现持久性和容错。Celld 结合了这些思想，为特定云提供商的实现提供了自托管替代方案。

## [LLM 0.32 新增推理轨迹、服务端工具和更智能的日志](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 7.0/10

LLM 0.32 于 2026 年 8 月 4 日发布，引入了推理模型的可视化推理轨迹、服务端提供商工具（包括 OpenAI 的 CodeInterpreter 和 WebSearch），以及重新设计的内容可寻址 SQLite 日志。它还增加了对 GPT-5.6 模型系列的支持，并将 GPT-5.6 Luna 作为新的默认模型，以及一个新的 'llm openai endpoint' 命令，用于针对任何兼容 OpenAI 的端点执行一次性提示。 此版本显著增强了 LLM CLI 对开发者和研究人员的实用性，使调试推理模型和利用服务端工具变得更加容易，无需复杂设置。服务端工具和 OpenAI Responses API 支持的加入，使 LLM 成为与各种 LLM 提供商交互的更强大、更灵活的接口。 推理轨迹默认显示到标准错误，可通过 -R/--hide-reasoning 标志禁用。llm-anthropic 插件也获得了重大更新，包括 WebSearch、WebFetch、CodeExecution 和 AnthropicMCP 工具。新的 'llm openai endpoint' 命令不记录提示，非常适合快速、无日志的测试。

rss · Simon Willison · 8月4日 23:58

**背景**: LLM 是 Simon Willison 开发的一款流行的开源命令行工具和 Python 库，用于与大型语言模型交互。它支持多种提供商和模型，允许用户运行提示、管理对话和使用工具。OpenAI Responses API 是 OpenAI 于 2025 年 3 月发布的开发者工具，旨在通过将聊天补全与高级工具调用功能相结合来简化代理应用程序。SQLite 日志中的内容可寻址存储意味着日志根据其内容哈希存储，从而实现去重和高效检索。
